# GameDev Start

Sitio educativo en español que presenta una ruta básica de programación para videojuegos con Luau en Roblox Studio. Este repositorio se prepara para la práctica escolar de introducción a GitHub y control de versiones.

## Contenido

La página muestra una ruta de aprendizaje, una primera lección con código de ejemplo y una propuesta de proyecto. Incluye navegación adaptable y un botón para copiar código. Es una web informativa inicial: presentar una ruta de módulos no significa que todos los módulos estén desarrollados como lecciones completas.

## Archivos

| Archivo | Función |
| --- | --- |
| `index.html` | Estructura y contenido de la página. |
| `styles.css` | Colores, tipografía y distribución adaptable. |
| `script.js` | Menú móvil y botón para copiar código. |
| `assets/hero-code.svg` | Ilustración principal. |
| `assets/favicon.svg` | Icono de la pestaña del navegador. |
| `netlify.toml` | Configuración de publicación y encabezados para Netlify. |
| `GUIA_NETLIFY.txt` | Instrucciones originales del despliegue manual. |

## Cómo abrir el proyecto

1. Descarga y extrae el ZIP, o clona el repositorio cuando esté publicado.
2. Conserva todos los archivos y la carpeta `assets` juntos.
3. Abre `index.html` en el navegador.

No requiere instalar dependencias ni ejecutar una compilación. La función de copiar utiliza el portapapeles del navegador y puede depender de sus permisos y del contexto de seguridad. Si no funciona al abrir el archivo localmente, selecciona el código y cópialo manualmente.

## Uso de GitHub en esta práctica

El repositorio permite documentar la página y conservar sus cambios. Para la carga inicial se propone el mensaje de commit: `Agregar sitio GameDev Start y documentación inicial`. Después se pueden guardar mejoras mediante nuevos commits con mensajes descriptivos.

La publicación y el historial real se comprobarán en GitHub después de subir los archivos. Este README no afirma que esa publicación ya se haya realizado.

## Publicación web

El código puede almacenarse en GitHub mientras el sitio continúa publicado en Netlify. Subir archivos al repositorio no publica automáticamente una página web. La dirección del repositorio y la dirección del sitio son enlaces distintos.

## Nota sobre el lenguaje

Roblox Studio utiliza Luau, un lenguaje derivado de Lua. Los ejemplos están pensados para estudiar programación aplicada a videojuegos.
